# CORE - 高端频率计核心计算模块

本项目是高端频率计的核心计算模块，基于 **Xilinx ZYNQ7020** 核心板实现高精度频率测量。系统采用 **FPGA 采集 + DDR 存储 + ARM 计算** 的异构协同架构，充分发挥 ZYNQ 平台 PL（可编程逻辑）与 PS（处理系统）协同工作的优势，实现高精度、高实时性的频率测量。

## 核心架构

```
┌─────────────────────────────────────────────────┐
│                 ZYNQ7020 核心板                  │
│                                                  │
│  ┌────────────┐   AXI   ┌─────────┐   ┌───────┐ │
│  │ FPGA (PL)  │ ──────► │   DDR   │ ─► │ ARM   │ │
│  │ 信号采集    │         │ 数据缓存 │    │ (PS)  │ │
│  │ 高精度计数  │         └─────────┘    │ 频率  │ │
│  └────────────┘                        │ 计算  │ │
│                                        └───────┘ │
└─────────────────────────────────────────────────┘
```

- **FPGA 采集**：利用 PL 端实现高速信号采集与精密计数，保证测量闸门时间的硬件级精度
- **DDR 存储**：采集数据经 AXI 总线高速写入 DDR，实现大容量、连续测量数据缓存
- **ARM 计算**：PS 端运行本仓库固件，完成数据处理、频率解算与结果输出

## 固件分层设计

固件采用四层架构，配合 `boards/` 板级配置系统实现多硬件平台适配：

| 层级 | 职责 |
|------|------|
| `app` | 应用逻辑：测量流程控制、频率解算、结果管理 |
| `services` | 通用服务：日志、通信协议、系统服务管理 |
| `hal` | 硬件抽象：统一接口，隔离平台差异 |
| `drivers` | 外设驱动：PL 端数据交互、外设控制 |

## 构建

固件使用 CMake 构建：

```powershell
cd firmware
cmake -B build
cmake --build build
```

也可使用项目脚本：

```powershell
python tools/scripts/build.py
```
